## 合意と現在の動作

- PeerCast の公開 PCP 中継は制限しない。認証は自サイトの視聴・配信と帯域利用を制限するためのもの。
- `/` は YP＋自ノードのチャンネル一覧。カード全体が `/channels/<id>` へのリンクで、アイコン・説明・余白もクリック可能。
- 個別視聴は入場時に自動再生を試み、音声付き再生が拒否されればミュートで再試行。再生・停止・音量・全画面等は標準動画 controls。独自の「視聴する」「再生を開始」「全画面」「ミニプレイヤー」ボタンは置かない。
- ライブの時間軸・シークバーを Chromium / WebKit の CSS で隠している。Firefox や OS 独自全画面プレイヤーへの保証はない。シーク機構そのものを無効化する変更ではない。
- サイトは白基調で OS のダーク設定にも白を維持。スマホ向けに余白・操作領域を調整し、右上のメニューに一覧・配信・ログアウトを集約。
- フッターに小さな `/admin` リンク。管理 UI は別パスで、配信開始・ストリームキー発行フォームは削除済み。利用者の `/broadcast` には自分の配信・キー操作を残す。管理 RPC の認証や配色は別。
- 一覧・詳細の文字情報はぺからいぶを参考に、名前、ジャンル・説明・配信者コメント、既知の人数・経過時間を表示。詳細情報は動画下。
- アイコンはぺからいぶの SP / TP / その他の固定画像を同梱。個人アバター取得ではない。出典は [assets/README](../../ui/src/assets/README.md)。
- 最後の修正は `sp@@` 等の YP4G 制御部分の表示除去。例 `sp@@ - 真・女神転生Ⅴ Vengeance` → `真・女神転生Ⅴ Vengeance`。一覧・詳細・検索に適用し、元のジャンルデータは保持。通常語 `sports` / `space` は壊さない。

## バックエンド・参照先

- `internal/catalog`: `updateYPChannels` とサイトで共有する YP HTTP 一覧キャッシュ。要求時更新、60 秒有効、バックグラウンド定期取得ではない。画面は 10 秒ごとに API を読むが YP へ毎回取りに行かない。取得失敗時は成功から 5 分未満の古いデータを利用可能。取得状態は API に残し、視聴画面には出さない。
- `internal/site/directory.go`: サイト一覧、カタログに載る public tracker からの認証付きオンデマンド中継。任意 tracker を利用者から受け付けない。

- `channelView` に任意 `comment` / `uptime` を追加済み。YP の配信時間をローカル中継の開始時間で上書きしない。

## 開発環境を再開する

終了時に設定ファイルの非秘密フィールドだけを確認した値：RTMP `1945`、PCP / 管理 API `7154`、`site.enabled=true`、`site.dev_login=true`、`site.listen="127.0.0.1:8080"`、`site.origin="http://localhost:5173"`。設定はユーザーが変更し得るので、再開時の値を確認すること。

YP の `channels_url` は 0yp `https://yayaue.me/yp/index.txt`、SP `http://bayonet.ddo.jp/sp/index.txt`、p@YP `https://p-at.net/index.txt` が設定済み。以前の記録にある「p@YP 未設定」は現在の設定には当てはまらない。引き継ぎ時に外部 URL の疎通再確認はしていない。

既存のユーザープロセスを無断で停止・二重起動しない。起動が必要ならリポジトリ直下で：

```sh
go build -o peercast-mi .
./peercast-mi
```

別ターミナルで：

```sh
cd ~/src/go/peercast-mi/ui
npm run dev
```

- ブラウザーは `http://localhost:5173/`。管理は `/admin`、配信は `/broadcast`。
- `npm run dev` はリポジトリ直下ではなく `ui/` で実行。Go の起動も必要。
- Vite は `/site/`・`/auth/` を既定 `http://127.0.0.1:8080` に転送。管理 `/api/1` は転送しない。
- 管理 API の UI 既定値は `7144`。現在の Go 設定 `7154` を使うには `VITE_PEERCAST_ENDPOINT` を合わせる（`ui/README.md`）。今回、秘密情報を避けるため `.env.local` は読んでいない。
- 開発用ログインは loopback 限定、X の登録不要。ただし操作は実ノードに反映される。公開運用では無効化し通常の X 認証を設定する。
