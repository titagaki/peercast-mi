# 0026: サイト一覧の掲載対象はYPカタログで決める

- 状態: 採用
- 日付: 2026-09-14

## 背景

0ypへ掲載されていない配信枠がmiに表示された。ユーザーは0ypのindex.txt取得分だけを一覧に載せるよう指定した。

## 決定

サイトのchannels/directory APIはYPカタログにあるIDだけを返す。ローカルチャンネルの受信状態などは同じIDが掲載されている場合のみ補完する。本人用配信APIと管理パネルはローカル状態を維持する。本番の取得元はインフラ設定のchannels_urlで0ypのみに絞る。アプリには特定YP名を固定しない。

既存カタログのキャッシュ（通常1分、取得失敗時の過去データ最大5分）は維持する。これは一覧表示の判断であり、既存視聴接続を強制終了する変更ではない。

## 却下した案

ローカルの配信枠を無条件追加する従来動作は、YP掲載済みと誤認させるため採用しない。取得失敗時にローカル一覧へ切り替える方法も同じ問題がある。
