# 0024: 指定Xユーザーだけにサイト管理APIを提供する

- 状態: 採用
- 日付: 2026-09-14

## 背景

本番の管理画面が閲覧者PCのloopbackへ接続しており利用できなかった。ユーザーは管理パネルの復旧を依頼し、認証方式として特定のXユーザーを指定した。

## 決定

- `site.admin_x_ids` で管理者の数値IDを明示する。空設定では全員拒否。開発用ログインには権限を付与しない。
- サイトの `/admin/api/1` でセッション・許可ID・Origin・CSRFを検証してから、固定のloopbackノードAPIに中継する。全JSON-RPCメソッドを管理者に提供する。
- UIは本番では同一オリジンの管理入口を利用し、ログインと権限を確認してから管理画面を表示する。APIはUIに依存せず毎回認証する。
- ADR 0019 の管理APIをサイトに提供しない方針を、この管理者専用経路に限って変更する。既存ノードAPIのBasic認証と一般視聴者の権限は維持する。

2026-09-16追記: 同一プロセスの管理ハンドラーへの引き継ぎに変更した。認証条件は維持し、操作者をcontextで渡す。[ADR 0032](0032-site-audit-mariadb.md) を参照。

## 却下した案

- Basic認証の別アカウント: 最終的なユーザー指定はXの特定アカウント。
- 一般Xログイン成功者全員に管理権限を付与: 発行済みキー・ノード設定を一般利用者に公開する。
- Caddyからlocalhostの管理APIへ無認証転送: loopback認証例外を外部公開する。
- 表示名で許可: 表示名は本人が変更でき、同名の利用者を識別できない。
