# 0027: サイト配信のジャンルに掲載用yp接頭辞を補う

- 状態: 採用
- 日付: 2026-09-14

## 背景

0ypはジャンルのyp接頭辞を掲載条件とするが、サイトは入力値をそのまま送信していた。ユーザーは掲載不具合の解消を求めている。

## 決定

サイトの配信作成APIでジャンル前後の空白を除去し、小文字ypで始まらなければ補完する。空欄はyp、既存のyp制御文字列は維持。長さは補完後256 bytesまで。ノードの汎用管理APIやBCST送信層では自動補完しない。作成済みチャンネルを遡って書き換えない。

## 理由と却下した案

入力者が掲載制御文字を知っている前提をなくす。手動指定の案内だけでは空欄・通常ジャンルで同じ不具合が再発する。すべてのノード送信で補完すると管理APIからの意図的な未掲載まで変更するため、サイト作成時に限定する。
