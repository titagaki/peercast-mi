# 一覧・視聴ページの視聴人数は YP の値で統一する

## 状態

採用

## 日付

2026-09-15

## 背景

ローカルで中継を開始すると、一覧・視聴ページの視聴人数を YP の値から自ノードの TotalListeners に置き換えていた。この値は自ノードへの HTTP 視聴接続と下流ノードからの報告の合計であり、配信全体の人数としては使えない。ユーザーと、YP の人数で統一し非公開・不明は非表示とする方針を合意した。

## 決定

- channels / directory API の視聴人数は、採用した YP カタログの値を保持する。ローカルの配信・中継の有無に依存させない。
- YP の負数・不明は画面で非表示とし、ローカル人数で補完しない。
- 自ノードの人数集計、PCP 報告、本人用配信 API・管理 API は維持する。

却下した案: ローカル人数を優先・補完に使う方式は集計範囲が異なり、視聴開始前後で数値の意味が変わるため採用しない。非公開の人数をローカル集計で表示することも避ける。

## 結果・影響

一覧・視聴ページは YP カタログの更新周期に従う。サイトで再生を始めても人数が即座に増えるとは限らない。同一 ID が複数 YP にある場合の選択順序は維持する。
