# 0028: NAT内ノードの公開IPv4を明示設定できるようにする

- 状態: 採用
- 日付: 2026-09-14

## 背景

同一Dockerネットワークの0ypがmiの内部IPをOLEHで返し、miがHOSTの公開欄へその値を載せていた。ユーザーは修正を依頼した。

## 決定

public_ipv4指定時、HOSTの公開IPv4は設定値を優先する。自動OLEH観測とポート判定は維持し、未指定環境の動作を変えない。PCPの既存HOSTフィールドを使用し、ワイヤ形式を追加しない。

## 理由と却下した案

0ypへの接続をVPS公開IP経由にするだけではNAT折り返し時の観測値が公開IPとは限らない。内部接続を維持し広告アドレスを明示する。固定IPをコードに埋め込まず運用設定に置く。DNS変化を暗黙に追従する挙動を避け、IPv4リテラルに限定する。

内部YPのping成功は外部疎通を保証しないため、公開ポートは別途確認する。今回外部から153.127.50.98:7154へのTCP接続は成功した。外部PCP視聴の成功とは区別する。
