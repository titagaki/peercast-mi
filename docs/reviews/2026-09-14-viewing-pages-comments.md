# 視聴ページの分離・自動再生・掲示板コメント

日付: 2026-09-14。ユーザー指定の画面変更を実装。既存の開発ログイン・YP 一覧などの未コミット変更を保持して追加した。判断は [ADR 0022](../decisions/0022-viewing-pages-and-comments.md)、現在の仕様は [site.md](../spec/site.md)。

## 実装範囲

| 要求 | 実装 |
|:--|:--|
| `/` にチャンネル一覧 | ログイン後に一覧・検索を表示。チャンネル名を通常リンクに変更 |
| 個別視聴ページ | `/channels/<id>`。URL 直アクセス / リロードにも対応 |
| 開くと再生 | ページで自動接続・自動再生。音声付きが拒否されたらミュートで再試行 |
| 掲示板 | したらば・JPNKN のスレッド選択、最新 30 レス、10 秒更新、投稿なし |
| YP の技術的状態を非表示 | 閲覧 UI から削除。診断用 API の sources は保持 |
| 独自の再生操作を削除 | 「視聴する」「再生を開始」「全画面」「ミニプレイヤー」「視聴を閉じる」は置かず、標準 video controls を利用 |
| 配信する | `/broadcast` へのリンクをボタン状に表示。本人のキー発行・配信管理を維持 |
| フッター文言 | 「公開 PCP 中継 / 認証付きサイト視聴」を削除 |
| 管理を別パスへ | `/admin`。管理 API 自体をサイトから転送しない |
| 管理パネルから配信開始・キー発行を削除 | フォーム・ダイアログとそれらに到達するボタンを削除。既存キー閲覧 / 失効、チャンネル管理、RPC メソッドは維持 |

## 検証結果

- `go vet ./...` / `go test ./...` 成功。
- `go test -race ./internal/site ./internal/catalog ./internal/servent` 成功。
- 掲示板 URL の許可・拒否、UTF-8 / EUC-JP / Shift_JIS、件数・番号・順序・改行・エンティティ、スレッド選択、キャッシュ集約・サイズ上限、認証、任意 URL / 改ざん thread の拒否、ページルート、X ログイン後の元ページ復帰をテスト。
- `npm run lint` / `npm run build` 成功。Playwright 51 件成功（desktop / mobile / dark）、`npm run test:proxy` 成功。
- ブラウザーでは一覧で映像要求なし、名前リンクからの自動再生、直 URL / 再読み込み、音声付き autoplay 拒否時のミュート切替、video 内の pause、コメント表示・スレッド選択・10 秒更新・HTML 非実行、不要操作がないことを確認。
- スレッド選択テストの最初の実行はラベル取得の完全一致指定で失敗した。実画面の accessible role/name に合わせた combobox 指定に変更し、再実行成功。仮想時計もページロード前に設定して定期更新を確認した。
- desktop / mobile / dark の動画・掲示板画面のスクリーンショットを目視。狭い画面は縦並び、横幅超過なし。ダークモードの配信リンクの文字色を補正。
- 読み取り専用の実 BBS 確認（`PEERCAST_TEST_BOARD_URL` 指定の `TestLiveBoard`）: JPNKN の板は 36 スレッド / 最新 30 レス（最新番号 796）、したらばの板は上限 200 スレッド / 最新 30 レス（最新番号 610）を取得・解析。取得時点の結果であり固定件数ではない。投稿は行っていない。通常テストではこの外部通信を skip する。

ブラウザー試験の映像・コメント API は mock、映像は生成 H.264/AAC FLV。実掲示板の読み取りは Go の取得処理で別に確認した。外部 X 本番ログイン、実番組の PCP 受信からブラウザーまでの一連の相互接続、Safari / スマホ実機は未検証。稼働中のユーザーノード・Vite は再起動していない。
