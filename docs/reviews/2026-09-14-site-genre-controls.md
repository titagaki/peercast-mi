2026-09-14。ユーザー報告の `sp@@ - 真・女神転生Ⅴ Vengeance` から `sp@@` を除外する表示修正。

## 資料と確認範囲

ローカル checkout を参照。以下の作業ツリーはすべて clean。GitHub main の最新との差分は未確認。

`?` は人数非表示、`@` はポートチェック、`@@` はビットレート基準の帯域チェック、`@@@` は 2Mbps 固定のチェック指定。ジャンル本文ではない。

## 修正と差異

- `ui/src/site-channel-text.ts#channelExplanation` で表示用ジャンルだけを整形。一覧・詳細・検索に共通適用。
- `sp@@` → 空、`sp@@ゲーム` → `ゲーム`、`ypABC:?@@ゲーム` → `ゲーム`。空のジャンルに区切りは付けない。
- 接頭辞は yp / sp / tp。参照 pcgw の任意 `.p` より限定し、未知の識別子は推測で削除しない。
- 掲載済みの通常ジャンルと PCP の制御付きジャンルが混在するため、`sports` / `space` のような英数字直結で制御記号のない曖昧な文字列は保持する。0yp の無条件の yp 除去とは異なる。日本語本文や明示的な記号のある書式は処理する。
- 先頭だけを処理し、ジャンル本文中の `sp@@` や一般的なコロンは保持。
- カタログ・サイト API・PCP・管理 UI の元データは未変更。人数の秘匿や帯域チェックをサイトで再実装するものではない。

以前の [YP 一覧調査](2026-09-14-yp-directory.md) はカタログが掲載済みジャンルを保持する判断。今回は表示層の追加処理であり、その判断は維持する。
