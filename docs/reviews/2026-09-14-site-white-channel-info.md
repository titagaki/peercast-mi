## 対応と意図的な差異

| 項目 | peercast-mi の対応 | 根拠・差異 |
| --- | --- | --- |
| 色 | サイトは常に白背景、濃いグレーの文字 | 今回のユーザー要望。管理側のダーク対応は維持 |
| 文字 | 名前と `ジャンル - 説明 コメント` をまとめる | ぺからいぶの情報構成を参照。サムネイル・お気に入り等の機能は追加しない |
| 表示整理 | 説明の帯域タグ、ジャンル中の独立した game を省略 | 元データは保持。ぺからいぶの正規表現は単語の途中も削るが、こちらは Endgame 等を破壊しない |
| HTML | React の文字列描画のみ | カタログ取得時に実体参照を復号済み。表示時の二重复号・HTML 挿入は行わない |
| 視聴人数 | 0 以上の場合のみ表示 | 不明の -1 を人数として見せない |
| 経過時間 | 秒を分・時間・日へ切り捨てて表示 | ぺからいぶの丸め方とは異なる。過大な時間に丸めず、不明は非表示。YP の時間と自ノード中継の時間を混同しない |
| アイコン | SP / TP / その他の同梱画像を一覧・詳細で表示 | `ypIconUrl` と同じ選択。元の `public/images` の 3 画像をそのまま再利用。個人アイコン取得は参照元でも無効 |
| スマホ | テキストを折り返し、詳細は動画下に表示 | 参照元の横スクロール・nowrap は採用せず、前回のスマホ向け方針を維持 |

サイト API の ChannelView に任意の `comment` / `uptime` を追加。JSON-RPC の形式は未変更。YP の一覧をローカル中継情報で上書きするときも YP の uptime を残す。
