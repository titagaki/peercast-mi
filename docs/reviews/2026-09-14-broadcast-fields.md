# 配信フォームの入力項目復元

## 原因と修正

ユーザーから配信入力項目が減っているとの報告。旧管理画面の `0c9f1ed:ui/src/ChannelDialogs.tsx` の `InfoFields` と `BroadcastDialog` にはコメント・URL・ビットレートがあったが、サイトの配信フォームとAPIには配信名・ジャンル・説明しかなかった。

サイトにコメント・URL・ビットレートを復元し、APIで `ChannelInfo.Comment`・`URL`・`Bitrate` に渡す。本人のストリームキーをサーバー側で決定する既存の所有権制御は維持する。ビットレートは空欄で自動、明示値は1〜2147483647kbps。APIでは省略・0も自動。RTMPメタデータによる上書きは従来どおり。

URLは空またはHTTP(S)の絶対URLでユーザー情報を含まないものに限定する。任意の利用者が登録した値を視聴ページのリンクに使うため。コメント・URLは各2048bytesまで。従来の3項目だけのAPI要求も受け付ける。

## 検証

Goテストで新項目がチャンネル情報と表示用応答に残ること、省略時の自動設定、不正URL・負数・小数・範囲超過ビットレート・長すぎる文字列で配信枠を作成しないことを確認する。ブラウザーテストでは旧配信ワークフローに全項目の入力と送信値検査を追加する。

本番への適用・実OBS配信は未実施。チャンネル情報の永続化や配信中の編集機能はこの変更では追加していない。
