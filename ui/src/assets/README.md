# チャンネルアイコン

`yp-sp.png`、`yp-tp.png`、`mouneyou.png` はローカルの peca-live リポジトリ `public/images/` から変更せずに再利用。

- 参照コミット: `e21a01640fcc691a70818255b7ba2ece37d999f6`
- 選択規則: `app/javascript/packs/types/Channel.ts` の `ypIconUrl`（SP / TP / その他）。
- 配信者個人のアイコンではない。元画像の権利帰属を変更するものではない。

`yp-0yp.ico` は [peercast-0yp の favicon.ico](https://github.com/titagaki/peercast-0yp/blob/main/web/public/favicon.ico) を変更せずに再利用（Git blob SHA: `4d6251d7479c3c7b9cf9a963dfea6e65812d1659`）。YP 名が `0yp` のチャンネルに使用し、丸く切り取らず画像全体を表示する。
